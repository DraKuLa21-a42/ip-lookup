Network Tools
API Reference

Набір інструментів для аналізу мережевих адрес: геолокація IP, DNS-лукап, ICMP ping, TCP-перевірка портів та DNSSEC аналіз.

Base URL https://your-domain.com

Rate Limits

Ліміти запитів застосовуються per IP-адреса. При перевищенні — HTTP 429.

/api/dns
30
запитів / 60 сек
/api/ping
10
запитів / 60 сек
/api/tcpcheck
10
запитів / 60 сек
інші ендпоінти
30
запитів / 60 сек
⚠ При перевищенні ліміту API повертає {"error":"Забагато запитів. Ліміт: N за M сек"} зі статусом 429.

Безпека (SSRF захист)

Всі endpoint'и, що приймають host/IP/domain, захищені від SSRF-атак.

ℹ Приватні та зарезервовані IP-діапазони заблоковані: 10.0.0.0/8, 192.168.0.0/16, 127.0.0.0/8, 169.254.0.0/16 (AWS metadata) та інші RFC-зарезервовані діапазони. Домени, що резолвляться у приватні адреси, також заблоковані.

GET
/api/query?q={ip_or_domain}
Універсальний endpoint — автоматично визначає IP чи домен
▾
ℹ Якщо передано IP — поведінка як у /api/lookup. Якщо передано домен — як у /api/resolve. Поле "type" у відповіді завжди вказує "ip" або "domain".
Параметри
Параметр Тип Опис
qrequired string IP-адреса або доменне ім'я. 
GET /api/query?q=1.1.1.1

# Відповідь містить type: "ip" та geo-дані
GET /api/query?q=cloudflare.com

# Відповідь містить type: "domain" та results[] з geo-даними
GET
/api/dns?domain={domain}&type={type}
DNS-записи домену. Підтримує 30+ типів та DNSSEC перевірку
▾
Параметри
Параметр Тип Опис
domainrequired string Доменне ім'я для DNS-лукапу.
typeoptional string Тип DNS-запису. Якщо не вказано — повертаються всі знайдені типи. Можливі значення: A, AAAA, CNAME, MX, NS, TXT, SOA, SRV, CAA, DNSSEC та інші. 
GET /api/dns?domain=google.com&type=MX
GET /api/dns?domain=google.com

# Повертає всі знайдені типи + dnssec об'єкт
GET /api/dns?domain=cloudflare.com&type=DNSSEC

# Перевіряє DNSKEY, DS у батьківській зоні, RRSIG підписи

GET
/api/tcpcheck?host={host}&ports={ports}
Паралельна перевірка TCP-портів. До 100 портів за запит
▾
Параметри
Параметр Тип Опис
hostrequired string IP-адреса або домен.
portsrequired string Порти для перевірки. Формати:
• Один порт: 22
• Список через кому: 80,443,22
• Діапазон: 80-90 (макс. +100 від початку)
• Змішаний: 22,80,443,8080-8090
Максимум 100 портів за запит. Діапазон 1–65535.

Загальні помилки

Структура помилки однакова для всіх endpoint'ів.

// Відсутній або невалідний параметр
{ "error": "Параметр domain не вказано" }

// SSRF захист спрацював

// Rate limit перевищено
{ "error": "Забагато запитів. Ліміт: 10 за 60 сек" }
