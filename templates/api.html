Network Tools
API Reference

Набір інструментів для аналізу мережевих адрес: геолокація IP, DNS-лукап, перевірка SSL-сертифікатів, ICMP ping, TCP-перевірка портів, DNSSEC аналіз, WHOIS та RDAP.

Base URL https://your-domain.com

Rate Limits

Ліміти запитів застосовуються per IP-адреса. При перевищенні — HTTP 429.

/api/dns
30
запитів / 60 сек
/api/ssl
10
запитів / 60 сек
/api/ping
10
запитів / 60 сек
/api/tcpcheck
10
запитів / 60 сек
/api/whois
30
запитів / 60 сек
/api/rdap
30
запитів / 60 сек
інші ендпоінти
30
запитів / 60 сек
⚠ При перевищенні ліміту API повертає {"error":"Забагато запитів. Ліміт: N за M сек"} зі статусом 429.

Безпека (SSRF захист)

Всі endpoint'и, що приймають host/IP/domain, захищені від SSRF-атак.

ℹ Приватні та зарезервовані IP-діапазони заблоковані: 10.0.0.0/8, 192.168.0.0/16, 127.0.0.0/8, 169.254.0.0/16 (AWS metadata) та інші RFC-зарезервовані діапазони. Домени, що резолвляться у приватні адреси, також заблоковані.

GET
/api/ssl?host={host}&port={port}
Перевірка SSL/TLS сертифікату — довіра, термін дії, SAN, шифр
▾
ℹ Отримання сертифікату і перевірка ланцюжка довіри виконуються незалежно — навіть прострочені або self-signed сертифікати повністю аналізуються. Перевірка wildcard SAN відповідає RFC 6125.
Параметри
Параметр Тип Опис
hostrequired string Домен або IP-адреса. Приватні адреси заблоковані.
portoptional integer TCP-порт. За замовчуванням: 443. Діапазон: 1–65535.
Поля відповіді
Поле Тип Опис
valid boolean Загальний результат: сертифікат довірений, не прострочений, ім'я збігається.
trusted boolean Ланцюжок довіри перевірено системними CA.
trust_error string | null Причина недовіри (якщо є). Наприклад: self-signed, прострочений CA тощо.
name_match boolean Відповідність host і SAN/CN сертифікату. Підтримує wildcard *.example.com.
days_left integer Днів до закінчення дії. Від'ємне значення — сертифікат прострочений.
expired boolean true якщо сертифікат прострочений.
not_before / not_after string Дати початку і закінчення дії сертифікату.
san string[] Список DNS-імен із Subject Alternative Names.
tls_version string Версія TLS протоколу: TLSv1.2 або TLSv1.3.
cipher string Назва активного шифру (наприклад, TLS_AES_128_GCM_SHA256).
chain object[] Масив з CN, організацією, видавцем та датами для кожного сертифікату в ланцюжку.

/api/tcpcheck?host={host}&ports={ports}
Паралельна перевірка TCP-портів. До 100 портів за запит
▾
Параметри
Параметр Тип Опис

• Один порт: 22

GET
/api/whois?q={ip_or_domain}
WHOIS-інформація для домену або IP-адреси
▾
ℹ Endpoint автоматично визначає тип запиту — домен або IP. Для доменів використовується python-whois, для IP — системна команда whois із парсингом ключових полів. Контактні дані можуть бути приховані через GDPR/редакцію реєстратора.
Параметри
Параметр Тип Опис
qrequired string Доменне ім'я або IP-адреса. Приватні IP заблоковані.
Поля відповіді — домен
Поле Тип Опис
type string Завжди "domain".
domain string Нормалізована назва домену.
registrar string | null Назва реєстратора.
registrar_url string | null URL реєстратора.
whois_server string | null WHOIS-сервер реєстратора.
status string | string[] Статуси EPP домену (наприклад, clientTransferProhibited).
name_servers string[] Список NS-серверів (lower-case, дедупліковані).
created / updated / expires string | null Дати реєстрації, оновлення та закінчення у форматі ISO 8601.
dnssec string | null Статус DNSSEC з WHOIS (наприклад, unsigned).
registrant_name / registrant_org string | null Дані власника (можуть бути приховані GDPR).
registrant_country / registrant_city string | null Географія власника.
registrant_email / admin_email / tech_email string | null Контактні email (часто приховані).
raw string Повний сирий текст WHOIS-відповіді.
Поля відповіді — IP
Поле Тип Опис
type string Завжди "ip".
ip string Запитана IP-адреса.
netname string | null Назва мережі (NetName / netname).
netrange string | null Діапазон адрес мережі (NetRange / inetnum).
cidr string | null CIDR-нотація блоку (CIDR / route).
country string | null Код країни.
org string | null Організація-власник блоку.
abuse_email string | null Email для репортів зловживань.
rir string | null Регіональний реєстр: ARIN, RIPE, APNIC, LACNIC, AFRINIC.
raw string Повний сирий текст WHOIS-відповіді.

/api/rdap?q={domain_ip_or_asn}
RDAP (RFC 9083) — структурований аналог WHOIS для домену, IP або ASN
▾
ℹ RDAP — сучасна заміна WHOIS із JSON-відповіддями та стандартизованою структурою (RFC 9083 / RFC 9224). Сервер автоматично обирає потрібний RDAP-endpoint через IANA bootstrap (data.iana.org/rdap) з кешуванням на 1 годину. Підтримує домени, IPv4/IPv6 та ASN (AS15169 або просто 15169).
Параметри
Параметр Тип Опис
qrequired string Доменне ім'я, IP-адреса або ASN.
ASN можна передати як AS15169 або 15169.
Приватні IP заблоковані.
Поля відповіді — домен
Поле Тип Опис
type string "domain"
domain string LDH-назва домену (ldhName).
handle string | null Унікальний ідентифікатор об'єкта в реєстрі.
status string[] Масив статусів EPP.
created / updated / expires string | null Дати з events (ISO 8601).
name_servers string[] Авторитативні NS (lower-case).
dnssec_delegation boolean | null true якщо делегування підписане (secureDNS.delegationSigned).
dnssec_zone boolean | null true якщо зона підписана (secureDNS.zoneSigned).
entities object[] Контакти: registrant, registrar, abuse тощо. Кожен об'єкт містить roles, name, org, emails, address.
notices string[] Назви правових повідомлень від реєстру.
rdap_conformance string[] Профілі RDAP, яким відповідає відповідь.
raw object Повний розпарсений JSON від RDAP-сервера.
Поля відповіді — IP
Поле Тип Опис
type string "ip"
handle / name string | null Ідентифікатор та назва мережевого блоку.
type_ip string | null Тип алокації: ALLOCATED, ASSIGNED тощо.
start_addr / end_addr string Початкова та кінцева адреса блоку.
cidr string[] CIDR-нотація (з cidr0_cidrs).
country string | null Код країни реєстрації блоку.
parent_handle string | null Handle батьківського блоку.
entities object[] Контакти (registrant, abuse тощо).
Поля відповіді — ASN
Поле Тип Опис
type string "asn"
asn integer Номер автономної системи.
handle / name string | null Ідентифікатор та назва AS.
start_asn / end_asn integer | null Діапазон ASN блоку.
entities object[] Контакти організації.
