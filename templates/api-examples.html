Network Tools
REST API

Інструменти для аналізу IP-адрес, доменів, DNS-записів, пінгу та перевірки TCP-портів. Всі відповіді у форматі JSON.

Base URL

Base URL

Всі запити відправляються на сервер. У production замініть localhost:5000 на реальний домен.

Формат відповіді: завжди application/json.
Символ кодування — UTF-8. CORS не налаштовано — для браузерних запитів із зовнішніх доменів додайте відповідний middleware.

Rate Limits

Ліміти прив'язані до IP клієнта (враховується заголовок X-Forwarded-For).

ЕндпоінтЛімітВікно
/api/ping10 запитів60 сек
/api/tcpcheck10 запитів60 сек
/api/dns30 запитів60 сек
Решта30 запитів60 сек
429 Too Many Requests — при перевищенні ліміту сервер повертає код 429 і JSON з полем error.

GET /api/myip

Повертає IP-адресу клієнта, з якої прийшов запит. Підтримує IPv4 та IPv6. Корисно для визначення зовнішнього IP.

Параметри

Параметри відсутні.

Приклад запиту

cURL 
curl /api/myip
Відповідь 200 OK
JSON
{
  "ip":      "203.0.113.42",
  "version": 4
}

        GET
        /api/dns
        30 / 60s
      

      
Запит DNS-записів домену. Підтримує понад 20 типів записів, включно з перевіркою DNSSEC.


      
Параметри

      

        
ПараметрТипОбов'язковийОпис

        
          

            domain
            string
            required
            Доменне ім'я для DNS-запиту.
          

          

            type
            string
            optional
            Тип запису: A, AAAA, MX, TXT, NS, CNAME, SOA, DNSSEC та інші. Якщо не вказано — повертаються всі типи.
          

        
      


      
Підтримувані типи

      

        Основні: A, AAAA, CNAME, MX, NS, TXT, SOA, PTR

        Сервіси: SRV, CAA, NAPTR, SSHFP, TLSA, DNSKEY

        DNSSEC: DS, CDS, CDNSKEY, NSEC, NSEC3

        Сучасні: HTTPS, SVCB, CERT

        Спеціальний: DNSSEC — перевіряє підпис зони (DNSKEY + DS + RRSIG)
      


      

        

          cURL · всі записи
          
        

        
curl "/api/dns?domain=google.com"

      


      

        

          cURL · тільки MX
          
        

        
curl "/api/dns?domain=google.com&type=MX"

      


      

        

          cURL · перевірка DNSSEC
          
        

        
curl "/api/dns?domain=cloudflare.com&type=DNSSEC"

        10 / 60s
      

      
ICMP ping до хоста. Повертає статистику RTT (min/avg/max/mdev) та відсоток втрат пакетів.


      
Параметри

      

        
ПараметрТипОбов'язковийОпис

        
          

            host
            string
            required
            IP або домен. Приватні адреси заборонені.
          

          

            count
            integer
            optional
            Кількість пакетів від 1 до 10. За замовчуванням: 4.
          

        
      


      

        

          cURL
          
        

        
curl "/api/ping?host=8.8.8.8&count=4"

      


      

        Відповідь
        200 OK
      

      

        
JSON

        
{
  "host":        "8.8.8.8",
  "success":     true,
  "packet_loss": 0,
  "rtt": {
    "min":  9.12,
    "avg":  11.45,
    "max":  13.88,
    "mdev": 1.72
  },
  "output": "PING 8.8.8.8 ... 4 packets transmitted ..."
}

        GET
        /api/tcpcheck
        10 / 60s
      

      
Перевірка доступності TCP-портів. Підтримує окремі порти, списки та діапазони. Максимум 100 портів за раз. Перевірка виконується паралельно.


      
Параметри

      

        
ПараметрТипОбов'язковийОпис

        
          

            host
            string
            required
            IP або домен.
          

          

            ports
            string
            required
            
              Список або діапазон портів.

              80 — один порт

              80,443,22 — список

              8080-8090 — діапазон (max 100 від початку)
            		
          

        
      


      

        

          cURL · список портів
          
        

        
curl "/api/tcpcheck?host=github.com&ports=22,80,443"

      


      

        

          cURL · діапазон
          
        

        
curl "/api/tcpcheck?host=example.com&ports=8080-8090"

      


      

        Відповідь
        200 OK
      

      

        
JSON

        
{
  "host":    "github.com",
  "results": [
    {
      "port":    22,
      "open":    true,
      "ms":      14.32,
      "service": "SSH"
    },
    {
      "port":    443,
      "open":    true,
      "ms":      12.18,
      "service": "HTTPS"
    }
  ]
}
